# Exercises

Store personal solutions here instead of editing the textbook source.

## Before coding

Record:

- the problem in one sentence;
- the expected input and output;
- a simple or brute-force approach;
- a prediction of time and space complexity;
- important assumptions.

## After coding

Check at least:

- empty input where applicable;
- the smallest valid input;
- duplicate or repeated values;
- already ordered and reverse-ordered data;
- a case that should fail or return no result;
- a larger input that exposes performance behavior.

## Completion criteria

An exercise is complete when I can:

1. trace it manually on a small input;
2. explain why it terminates;
3. state an invariant or another correctness argument;
4. derive its complexity rather than only naming it;
5. describe when I would and would not use the approach.

It is acceptable to commit incomplete attempts. Mark them clearly and record why the approach failed.
