# Experiments

Use this directory for small programs that test a claim, inspect a data structure, or measure practical behavior.

Experiments support understanding but do not replace a proof.

For each experiment, record:

- the claim being tested;
- the expected result before execution;
- the controlled inputs;
- the observed result;
- what the result does and does not establish;
- possible measurement errors or confounding factors.

Typical examples include comparing growth rates, timing list operations, counting recursive calls, and visualizing traversal order.
