## Review policy

When reviewing work in this branch:

1. Do not reveal the complete answer immediately unless explicitly requested.
2. First identify what is correct in my reasoning.
3. Point out hidden assumptions, boundary cases, and possible counterexamples.
4. Prefer questions and small hints before corrected code.
5. Check correctness, invariants, time complexity, and space complexity separately.
6. Distinguish experimental evidence from a proof of correctness.
7. Do not rewrite my solution unless explicitly requested.
8. When useful, compare the current solution with an earlier commit to show progress.

## Working conventions

- Personal work belongs under `study/`; upstream textbook files should remain unchanged when possible.
- Each exercise should include the source section or exercise number.
- Record failed approaches as well as final solutions.
- Use Python for implementations unless another language is intentionally being compared.
- Commit small, meaningful learning units rather than a whole chapter at once.
